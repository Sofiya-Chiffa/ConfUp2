Инструмент для анализа зависимостей Maven пакетов. Программа строит граф зависимостей, визуализирует его и предоставляет различные способы анализа.

Основные возможности:

    Анализ зависимостей Maven пакетов

    Построение графа зависимостей с учетом транзитивности

    Обнаружение циклических зависимостей

    Визуализация в формате SVG/PNG

    Фильтрация и ограничение глубины анализа

    Тестовый режим для отладки


Основные функции

Этап 1: Конфигурация

    Чтение настроек из YAML файлов

    Валидация параметров

    Обработка ошибок конфигурации

Этап 2: Сбор данных

    Получение зависимостей из Maven репозиториев

    Парсинг POM файлов

    Поддержка тестового режима

Этап 3: Построение графа

    BFS с рекурсией для анализа транзитивных зависимостей

    Обнаружение циклических зависимостей

    Фильтрация пакетов

    Ограничение глубины анализа

Этап 4: Дополнительные операции

    Определение порядка загрузки зависимостей

Этап 5: Визуализация

    Генерация Graphviz DOT файлов

    Создание SVG/PNG изображений

    ASCII-дерево зависимостей


Для корректной работы программы необходимо установить Graphviz.
